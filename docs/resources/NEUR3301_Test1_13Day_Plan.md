### The four bridges most likely to be tested

1. **Lineage vs position vs time** — a cell's fate is set by what it can become (potency), where it is (BMP/Wnt/Shh/Hox), and when it is there (competence switch). MCQs love swapping one for another.
2. **Survival vs guidance** — trophic factors do both, and the exam will check you can separate them. NGF keeps a neuron alive *and* steers its growth cone; those are different experiments.
3. **Apoptosis vs pruning vs regeneration failure** — whole-cell death, branch removal, and adult repair failure are three distinct mechanisms with three distinct evidence bases.
4. **Glia as support vs glia as obstacle** — the same reactive astrocyte both limits damage and blocks regrowth. Any question forcing a single valence is testing whether you know it is a trade-off.

## Mechanism spines — the seven chains

Use these as retrieval targets. If you can write the chain from blank, that lecture is done.

**L1 Glia I** — cell types by mechanism not adjective (astrocyte / oligodendrocyte / microglia / ependymal) → radial glia as developmental progenitor → astrocytic K⁺ and transmitter clearance → myelin, conduction velocity and axonal metabolic support → microglial origin and surveillance → reactive astrocyte trade-off → Schwann cell repair programme in peripheral nerve.

**L2 Growth and trophic factors** — target-derived survival signal in limited supply → competition between innervating neurons → Trk receptor binding and retrograde transport to the soma → survival signalling suppresses intrinsic apoptosis → surplus neurons die → separate this from the guidance role of the same factors.

**L3 Axon outgrowth, target recognition, maps** — growth cone reads a cue → receptor and intracellular context convert the cue to attraction or repulsion → intermediate targets are reached and then escaped by changing responsiveness → CNS myelin and proteoglycans inhibit growth → graded Eph/ephrin signalling converts position to topographic map → hierarchy from region to target to layer to cell.

**L4 Regressive events and cell death** — apoptosis vs necrosis as regulated vs unregulated → intrinsic pathway through Bcl-2 family, cytochrome c release and caspase activation → target-dependent survival competition sets neuron number → bidirectional control between target size and afferent number → progressively selective regression: cell death, then axon pruning, then synapse elimination.

**L5 Cell lineage** — potency narrows as commitment increases → position and time convert location into identity (BMP, Wnt, Shh, and Hox as positional memory) → radial glia act as both progenitor and migration scaffold → a timed competence switch shifts output from neurons to glia → cortex assembles inside-out, birth order predicting layer, with Reelin required → excitatory neurons migrate radially, inhibitory interneurons tangentially → epigenetic access and miRNAs tune which fates remain reachable.

**L6 Adult neurogenesis / stem cells** — *pending slides; built after download.* Expect the core to be the evidence standard: what actually demonstrates self-renewal and multipotency, and why marker expression or a single label is not enough. Expect the human adult-neurogenesis controversy to be examinable as a limits-of-evidence question. **Highest-priority lecture in this test** — lowest coverage, only Beros lecture in scope.

**L7 Glia II** — *pending slides; built after download.* Expect it to extend L1 rather than repeat it. Note explicitly what it adds.
